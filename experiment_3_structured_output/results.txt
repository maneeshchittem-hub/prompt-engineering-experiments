========================================
PROMPT TECHNIQUES USED
========================================

1. Explicit JSON schema

The prompt clearly defined the required fields:

name, date, amount


2. Exact field names

The model was instructed to use exactly:

"name"
"date"
"amount"


3. JSON-only instruction

The model was instructed to return only JSON
without explanations or Markdown.


4. Data type instructions

The amount was required to be a number rather than
a string.

For example:

"amount": 55000


5. No additional fields

The prompt instructed the model not to create
extra fields.


6. Missing-value handling

The prompt specified what to return when information
is unavailable.


========================================
ANALYSIS
========================================

The structured output prompt successfully extracted the
required information from all five test inputs.

The explicit schema helped maintain a consistent output
format. The JSON-only instruction prevented additional
explanations from being included.

The field-name and data-type requirements also improved
consistency across different input formats, including
currency symbols such as ₹ and Rs.


========================================
CONCLUSION
========================================

The experiment demonstrates that explicit schema instructions,
JSON-only formatting, exact field names, and clear data-type
requirements can improve the reliability of structured output.

The model successfully returned the required information in
the defined JSON structure for all five test cases.

Overall success rate: 100%.
