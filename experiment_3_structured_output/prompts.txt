EXPERIMENT 3: STRUCTURED JSON OUTPUT
========================================

TASK:

Extract a person's name, transaction date, and transaction
amount from customer transaction text.

The output must be a valid JSON object using exactly the
following schema:

{
  "name": "string",
  "date": "string",
  "amount": 0
}


========================================
PROMPT
========================================

You are an information extraction system.

Extract the person's name, transaction date, and transaction
amount from the provided text.

You MUST return a single valid JSON object.

Use exactly this schema:

{
  "name": "string",
  "date": "string",
  "amount": 0
}

Rules:

1. Return JSON only.
2. Do not use Markdown code fences.
3. Do not add explanations.
4. Use exactly these field names:
   name, date, amount
5. Convert currency amounts to numbers without currency
   symbols or commas.
6. Do not create additional fields.
7. If a value is not available, use an empty string for
   name/date and 0 for amount.
